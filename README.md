# SMART CARE & LIFE SAFETY — 스마트 세이프티 음성 케어 솔루션 웹앱

고령자 낙상 사고 예방을 위한 **엣지 AI 기반 스마트 안전 케어 솔루션** 제안서를 인터랙티브 웹앱으로 구현한 프로젝트입니다.
원본 제안서 `낙상사고.pptx`(SMART CARE & LIFE SAFETY, 개발: 박서현, 2026.10.12)의 콘텐츠를 기반으로 제작했습니다.

> **핵심 메시지** — 낙상사고는 주의보다 **빠른 대처**가 필요합니다. 위험이 발생하는 바로 그 찰나, 공간이 먼저 인지하고 적시 음성으로 행동을 유도합니다.

---

## 1. 완료된 기능

### 메인 페이지 (`index.html`) — 솔루션 제안
- **히어로 섹션**: 핵심 슬로건 + 실시간 미니 데모 패널(4개 공간을 순환하며 위험 감지·음성 안내 시뮬레이션)
- **위험 4영역 카드**: 욕실(수분·시야) / 계단·복도(조도·장애물) / 침실(기상·균형) / 주방·현관(문턱·분주함)
- **3단계 대응 프로세스**: ① 상태 정밀 감지 → ② 위험 수준 및 문맥 판단 → ③ 현장 음성 및 보호자 전파
- **핵심 기능 소개**: 엣지 AI 분석, 멀티센서 융합, 맞춤형 음성, 고위험 에스컬레이션, 이력 리포트, 프라이버시 설계
- **도입 문의 폼**: 입력 검증(이름/기관/시설유형/연락처) + DB 저장 + 성공/실패 상태 안내
- 반응형 레이아웃(데스크톱/모바일), 스크롤 등장 애니메이션, 모바일 햄버거 내비게이션

### 관제 데모 페이지 (`dashboard.html`) — 실시간 안전 관제 콘솔
- **실시간 센서 시뮬레이션**: 4개 공간의 습도·조도·움직임·문턱 신호를 주기적으로 생성
- **공간별 위험 현황 평면도**: 정상(청록) → 주의(노랑) → 위험(주황) → 긴급(빨강) 4단계 시각화
- **음성 안내 콘솔**: 위험 감지 시 파형 애니메이션과 함께 실제 방송 문구 표시
- **실시간 이벤트 로그**: 발생 시각·공간·위험 유형·심각도·음성 문구
- **KPI 카드**: 모니터링 공간 / 세션 감지 이벤트 / 고위험 알림 / 음성 안내 실행 횟수
- **차트(Chart.js)**: 공간별 감지 비중(도넛), 심각도별 분포(막대)
- **컨트롤**: 일시정지/재개, 위험 시나리오 즉시 발생, 세션 초기화
- **토스트 알림**: 고위험 발생 시 우측 하단 실시간 팝업
- **저장된 감지 이력 테이블**: 위험·긴급 이벤트를 DB에서 조회

## 3. 기능 진입 URI (경로 및 파라미터)

| 경로 | 설명 | 주요 파라미터 |
|---|---|---|
| `index.html` | 메인 제안 페이지 | 앵커: `#risks`, `#how`, `#features`, `#contact` |
| `dashboard.html` | 실시간 관제 데모 | 없음 (클라이언트 시뮬레이션) |

### 사용 API 엔드포인트 (RESTful Table API, 상대 경로)
| 메서드 | 경로 | 용도 |
|---|---|---|
| `POST` | `tables/inquiries` | 도입 문의 접수 |
| `POST` | `tables/events` | 위험/긴급 감지 이벤트 저장 |
| `GET` | `tables/events?limit=200` | 저장된 감지 이력 조회 |

## 4. 데이터 모델

### `inquiries` — 도입 상담 신청
| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | text | 고유 ID (자동) |
| `name` | text | 담당자 이름 |
| `organization` | text | 기관/시설명 |
| `facility_type` | text | 가정 / 요양시설 / 의료기관 / 공공·지자체 / 기타 |
| `contact` | text | 연락처(전화 또는 이메일) |
| `message` | rich_text | 문의 내용 |
| `created_at` | datetime | 접수 시각 |

### `events` — 위험 감지 이력
| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | text | 고유 ID (자동) |
| `room` | text | 발생 공간 |
| `event_type` | text | 위험 유형 |
| `severity` | text | 낮음 / 주의 / 위험 / 긴급 |
| `message` | text | 상세 설명 |
| `voice_text` | text | 현장 음성 방송 문구 |
| `created_at` | datetime | 발생 시각 |

**저장 서비스**: Genspark RESTful Table API (프로젝트 데이터 스토어)

## 6. 아직 구현되지 않은 기능 / 제약 사항

- **실제 센서 연동 없음**: 현재 관제 화면은 엣지 AI 동작을 재현한 클라이언트 시뮬레이션입니다. 실제 IoT 센서·웹소켓 스트림 연동은 백엔드가 필요합니다.
- **실제 음성 합성(TTS) 없음**: 음성 안내는 텍스트와 파형 애니메이션으로 표현됩니다. 실제 스피커 방송은 Web Speech API 또는 서버 TTS 연동이 필요합니다.
- **보호자 앱/실제 알림 발송 없음**: SMS·푸시 등 외부 알림은 서버 사이드 기능으로 정적 사이트 범위를 벗어납니다.
- **관리자 인증 없음**: 인증·권한 관리는 서버가 필요합니다(정적 사이트에서는 진정한 보안 불가).
